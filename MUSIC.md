# Music

The shipped prototype uses an original procedural synth loop generated at runtime. It is intentionally locked to 120 BPM so jump, dash, obstacle, and quiz timing stay coherent, and it slows with the game during quiz gates.

For a later recorded soundtrack, a promising reference is [Game loops 001 simple mix 1 long loop 120 bpm](https://pixabay.com/sound-effects/musical-game-loops-001-simple-mix-1-long-loop-120-bpm-59010/), listed as a 120 BPM electronic game loop under the Pixabay Content License. Any downloaded replacement must be checked, bundled, and attributed separately before shipping.
